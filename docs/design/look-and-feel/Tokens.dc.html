Design system
Torchlit corridor
Dark stone, one warm light source per screen, quiet chrome. The humour lives in portraits, copy and motion — never in the panels. These are the values the Godot theme is built from.

Motion
Torch flicker
3.4s ease-in-out loop on the two glow blooms per screen; opacity .72–1, scale .97–1.02. Never on text.
Current node
2.2s pulse of the ember glow. Open nodes get a static 14px glow; locked nodes none.
Card hover
translateY(-18px) + ember border + glow in 180ms; play = card flies up and fades, damage number rises from the target.
Screen change
the light dims to the vignette (220ms), the new screen rises out of it (320ms). One reveal, no scattered micro-motion.
Descending a floor
the corridor backdrop's three layers scroll at 1×/0.6×/0.3× — the map gets visibly deeper.
